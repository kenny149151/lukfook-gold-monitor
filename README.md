# 六福内地金价自动监测

GitHub Pages 展示网站，GitHub Actions 每小时第17、47分钟采集。关闭电脑和浏览器后仍可执行。

主要来源：六福官方商城公开报价（含来源更新时间）；金价网补查黄金和PT950历史；新浪财经补查六福内地金条。9月7日前的断档另附人工核实的官方商城历史快照，记录在 `lukfook-history-supplement.json`。

## 规则

- 保留原始历史，官方同日较晚报价优先，每个品类保留自己的来源。
- 不把抓取时间当报价时间，不生成未来价格，不把未知报价冒充持平。
- 多金属走势、MA30、显示隐藏开关、三张独立月历、明细和客户文案均保留。
- MA30取最近30个有效报价日；切换显示范围不重置均线。
- 新月份会向前推进，页面范围上限2028-12-31。6月份仍可翻回查看。
- 金条/铂金未核实的历史字段留空，线图沿用值仅用于显示，不能视为当天实价。

## 启用

Settings → Pages → Source 选择 GitHub Actions，然后运行 Actions 中的 Collect prices and publish website。
正常上线后应打开 HTTPS 网站地址，而不是双击本地 HTML。

## 故障与持续运行

页面显示采集时间、官方报价时间及来源失败信息，超过3小时没有检查时提示超时。Actions失败会显示红色，可在GitHub个人通知设置中接收失败邮件。采集结果逐次提交到仓库，历史可以恢复。

GitHub定时任务可能排队、延迟或被跳过，不能保证精确半小时、午夜零点即有新价。官方当天未发布新报价时，显示上一报价日期与待发布提示。公众仓库60天无活动可能停用定时任务；正常采集会提交状态记录，仍应留意失败通知。

不要覆盖 `lukfook-prices.json` 以免丢失历史。只对本仓库授予Actions写入/Pages发布权限，不需要个人访问令牌。

本地预览：Node.js 22，运行 `node lukfook-sync-server.mjs`。测试：`node --test collector.test.mjs`。手动采集：`node collect-prices.mjs`。
